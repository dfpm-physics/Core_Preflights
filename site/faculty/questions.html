Import questions from a CSV

Paste rows from a spreadsheet, or choose a file. The first row names the columns. Required: format, prompt, points. The import only adds questions. If any row is wrong, nothing is written.

Columns and an example file
qid (optional, kept if given), format (multiple_choice, multiple_select, numeric, prose), prompt, points, choices (separated by |; they get the letters a, b, c ...), correct (letters or exact text, separated by |), value, tol_abs, tol_pct, sig_figs, sig_fig_mode, unit, unit_aliases, unit_mode, unit_hint, reference. A cell with a comma needs quotes around it. A correct value of 0 needs tol_abs.
