Use + - * / ^, round brackets, and the functions sin cos tan asin acos atan sinh cosh tanh sqrt exp ln log10 abs. pi and e are known, and so is sqrt(x) for a square root.
One to eight names, separated by commas. A name starts with a letter. Names such as sin and sqrt are taken. If you list e (the electron charge, say) or pi as a variable, it is YOUR variable in this question and the constant e or pi is not available to the answer or the key; the student page then shows a button for your variable and none for the constant. A Greek letter and its Latin spelling (theta and the Greek theta) count as the same name.
By default every variable is tested on positive values only, so sqrt(k)/sqrt(m) matches sqrt(k/m) and sqrt(x^2) matches x. List a variable here (for example x, if x is a position or a charge with a sign) and it is also tested at negative values; then sqrt(x^2) no longer matches x.
What this checks, and what it does not
  • The answer and your expression are worked out at the same fixed set of values for the variables, and compared. The values are fixed for a question, so a re-mark gives the same result. Every variable is tested on positive values only unless you list it under "Variables that can be negative", so with positive values sqrt(x^2) matches x and ln(a)-ln(b) matches ln(a/b). A listed variable is also tested at negative values.
  • It proves two expressions are equal, not that one is simplified. (x+1)^2 and x^2+2x+1 are both right.
  • A difference smaller than about one part in a billion is not seen. An answer that is undefined (a division by zero, a square root of a negative number) where your expression is defined is marked wrong. A difference is judged against the size of the numbers themselves, so a key such as 6.63e-34*f is not matched by 0.
  • A square root of a negative number has no real value: it is never read as 0 and never as a complex number. At a test value where your expression is undefined, nothing is asked; an answer that is undefined where yours is defined is marked wrong. A root whose argument is zero only up to rounding noise is read as 0. 1e3 is the number 1000; 2e and 2 e are 2 times the constant e (or your variable e), and with a variable called e, 2e3 and 2e+3 are still the number 2000.
  • Units, vectors and equations are not read. An answer is at most 200 characters.
  • An answer that cannot be read (an unknown name, a missing bracket, a division followed by juxtaposition such as 1/2x) is refused with a message and costs the student no attempt. Students must write 1/(2x) or (1/2)*x.
  • The key is checked on the server. A student's browser never receives your expression.
Prose is never marked by a machine. This is only a note for a human marker.

Import questions from a CSV

Paste rows from a spreadsheet, or choose a file. The first row names the columns. Required: format, prompt, points. The import only adds questions. If any row is wrong, nothing is written.

Columns and an example file
qid (optional, kept if given), format (multiple_choice, multiple_select, numeric, prose), prompt, points, choices (separated by |; they get the letters a, b, c ...), correct (letters or exact text, separated by |), value, tol_abs, tol_pct, sig_figs, sig_fig_mode, unit, unit_aliases, unit_mode, unit_hint, reference. A cell with a comma needs quotes around it. A correct value of 0 needs tol_abs.
