## What this page is

**All classes** is the first page you see after you sign in. If you are in more than one class that uses PREP, it puts the work from all of them in one list, so you do not have to open each class to find out what is due.

## How the list is ordered

- **Past due** comes first: work whose deadline has passed and that you did not hand in.
- **Due soon** is anything due in the next two days.
- **Later** is everything else that is open.

Inside each group the soonest deadline is first. Each row names its class, says whether you have not started it or have a draft saved, and shows your own deadline, including an extension you were given. Select a row to open that assignment in that class.

## What is not listed

An assignment appears here in the days before its deadline, the same as in each class. If a class has later work that has not opened yet, that class's card says so. Work you have already handed in is not listed.

## When something cannot load

If one class cannot be read, that class shows an error on its card and the page says the list may be incomplete. That is not the same as having nothing to do. Reload the page, and ask your instructor if it keeps happening. The other classes still show.

## Your classes

Each class has a card with its term and how much is open or past due. **Open class** goes to that class's own **Dashboard**. The **Dashboard**, **Assignments**, **Schedule** and **My grades** links in the top bar work on one class at a time; choose the class from the course name beside the PREP mark.
