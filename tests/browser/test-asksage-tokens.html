Before you trust a number

The system prompt is re-sent on every turn, so cost grows with turns and with the conversation behind them. Watch the input column climb: that shape, not the first turn, is the session cost.

If a reply arrives with no usage object the page says usage missing rather than counting it as zero. A silent zero would read as a free turn.
