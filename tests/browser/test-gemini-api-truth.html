Gemini API truth harness

Records what Google actually returns, verbatim, for every refusal the tutor can hit. It spends real quota on purpose. Use a disposable key.

Read this before you start.
A full run leaves this key's Flash models refusing until midnight Pacific (1am Mountain). That is the only way to see what a daily refusal looks like, which is the thing four shipped fix sets have each guessed at. Make a new key at aistudio.google.com for this, or accept that the key you paste is spent for the day. The key is never stored, never logged, and never written into the download.
The hard cap is absolute: the run stops at that many requests no matter what is still queued.
