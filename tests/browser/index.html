🎓 Gemini backup — does it still tutor? (needs your verdict) A cadet said the backup tutor "would try to tutor me and then give me the answer instead of walking me through it." The prompt was not the cause — it survives the port line for line. The model was: every conversation turn ran on the cheapest model we had, while the strongest was held back for the report an instructor reads. This candidate flips that — chat now runs 3.7 → 3.6 → 3.5 before the lite floor, study mode is pinned to lite so practice stops spending the graded allowance, and a rate limit no longer burns a model after 3.5 seconds. What we need: push back with a wrong answer and see whether it corrects you with a question or with a statement — and whether it holds that to the end, because the failure we are chasing starts well and degrades. Also carries the freeze fix. On 2026-08-21 a cadet reached the report stage and the page sat on "Tutor is typing…" forever — no request in the live builds has any timeout, so a connection Google never answers hangs the page with the composer and Send both disabled. The only escape was a reload, which erased the whole conversation. Now: every request has a two-minute deadline and fails to a Retry, the session is saved in your browser so a reload restores instead of erasing, and a 400 no longer tells you your API key is bad when the real cause is a conversation that got too long. Worth trying: reload the page halfway through and check your conversation comes back. Not synthetic: real PHYS 215 Lesson 2, real slug, and it wants your own free Gemini API key. Use Study mode — a graded run you actually submit writes a real submission.
