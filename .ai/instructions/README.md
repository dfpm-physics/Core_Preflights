# Shared AI instructions

`PROJECT.md` contains agent-neutral architecture and data-model context. The repository's
non-negotiable operating and safety rules remain in root `AGENTS.md` during the current transition.
Root `CLAUDE.md` imports both files; root `AGENTS.md` tells Codex and other compatible agents to
read this directory and discover `.ai/skills/`.

The previously discussed consolidation of shared material from `AGENTS.md` and `PROJECT.md` into a
single canonical core instruction file is intentionally deferred. Do not create a duplicate core
file in the meantime.
