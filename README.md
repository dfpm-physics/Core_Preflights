# iPREP (Core_Preflights)

iPREP is a static GitHub Pages and Supabase platform for USAFA Physics 110 and Physics 215
preflight assignments and lesson interactions.

- `site/` — deployed HTML, CSS, JavaScript, images, and the role-aware portal.
- `.ai/` — shared AI instructions, canonical skills, integrations, and artifact examples.
- `docs/` — operational, architectural, contract, and decision documentation.
- `scripts/` — standard-library Python maintenance and semester tooling.
- `supabase/` — database migrations, policies, functions, and scoped admin tools.
- `tests/browser/` — standalone browser sandboxes.

Start with [AGENTS.md](AGENTS.md) for live-system safety and operating rules. The production site
is <https://dfpm-physics.github.io/Core_Preflights/site/>.
